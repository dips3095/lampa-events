# Lampa Events

Расширение для Lampa: каталог событий с постерами, датами, выбором года и управлением пультом.

При выборе события расширение открывает штатный поиск раздач. Используются текущие настройки парсера и TorrServer. Адреса и ключи пользователя в исходниках не хранятся.

## Установка

Добавьте прямую HTTPS-ссылку на `events.js` в настройки расширений Lampa и перезапустите приложение. Раздел в меню — «События».

Постоянный адрес файла: https://dips3095.github.io/lampa-events/events.js

Адрес при обновлениях менять не нужно, включая уже сохранённые варианты с параметром версии. После публикации перезапустите Lampa; кеш GitHub Pages может обновляться до 10 минут.

Страница установки: https://dips3095.github.io/lampa-events/

## Источник данных

Основное расписание загружается из ESPN. TheSportsDB используется для доступных постеров и резервного списка. Бесплатный сезонный ответ TheSportsDB ограничен 15 событиями; резервный режим явно помечается как неполный и не кешируется. ESPN — публичный интерфейс без гарантии стабильности. Названия, даты и изображения поступают от поставщика; доступность и полнота данных могут меняться. Описания и результаты не отображаются.

Каталог не гарантирует наличие записей. Для просмотра требуется настроенный поиск и TorrServer.

Версия 0.1.5. Совместимость с конкретной сборкой Lampa на телевизоре требует проверки.

## Публикация

GitHub Actions публикует только `events.js` и `index.html` при изменении `main`. В Settings → Pages источником должен быть GitHub Actions. Если автоматическое включение Pages запрещено, владелец должен включить его один раз.

## Проверки

`node --check events.js` проверяет синтаксис. Для браузерных проверок установите `npm install --no-save playwright jquery`, затем `npx playwright install chromium` и выполните `node tests/smoke.cjs`. Для системного Chromium можно задать `CHROMIUM_PATH`.
