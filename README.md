# Lampa Events

Версия **0.2.0**. Каталог событий с **2010 года включительно** для Lampa с подборками, поиском по участникам и управлением пультом.

Постоянный адрес расширения: **https://dips3095.github.io/lampa-events/events.js**

Добавьте его в расширения Lampa и перезапустите приложение. При обновлениях адрес менять не нужно, в том числе если ранее сохранён параметр `?v=`. Раздел меню — **«События»**. Совместимость с конкретной сборкой на LG C2 требует проверки на телевизоре.

## Каталог и поиск

На главной: «Последние турниры», «Скоро», редакторская подборка «Лучшие турниры» и личный список «Посмотреть позже». Последний появляется после добавления первого события через меню карточки.

«Все турниры» открывает весь архив с 2010 года, порциями по 40 карточек. Фильтры: диапазон лет, месяц, серия и статус. Поиск охватывает название, номер, дату и всех известных участников, включая предварительные бои. Русские имена поддерживаются через транслитерацию и словарь вариантов; не любое произвольное написание будет распознано.

«Искать раздачи по этому запросу» передаёт произвольный текст штатному парсеру Lampa. Выбор турнира предлагает поиск по названию/номеру или дате. Используются существующие настройки парсера и TorrServer. Наличие события в каталоге не гарантирует наличие записи.

Оформленные обложки показываются сразу. При наличии проверенной афиши она заменяет обложку; отсутствие или ошибка изображения не мешает просмотру каталога. Результаты боёв, победители и описания исходов не публикуются.

## Данные

Основной источник — архив Sherdog и страницы событий. Включены основные турниры, телевизионные серии и финалы TUF; исключены отборочные шоу и эпизоды. Полнота списка сверяется с независимым перечнем событий. Исторические варианты названий, отмены и проверенные дополнения описаны в `data/reviews.json`. Неизвестная серия или неразобранное расхождение блокируют публикацию.

Индекс `data/catalog.json` содержит только разрешённые поля: идентичность события, название, дату, серию, статус, участников, ссылки на источники и изображения. Имена участников сортируются по алфавиту, чтобы порядок старых турнирных сеток не раскрывал победителей. Даты сохраняют календарную дату источника, без выдуманного времени начала.

TheSportsDB — дополнительный источник афиш. Используется только поле постера с проверкой названия/номера и даты. Сборка соблюдает ограничения запросов и продолжает работать с известными изображениями и оформленными обложками при блокировке этого сервиса. Незаполненные афиши проверяются по очереди, до 24 запросов за ежедневную сборку; наличие афиши для каждого события не гарантируется.

## Обновление и публикация

GitHub Actions запускается при изменении `main`, ежедневно в 03:00 UTC (06:00 МСК) и вручную. Списки обновляются ежедневно, составы предстоящих и недавних событий — ежедневно, старые составы — не реже раза в неделю. Ручной `full_refresh` принудительно перечитывает все составы.

Ветка `catalog-data` хранит последний проверенный каталог, очищенные данные составов и состояние афиш. Исходные HTML-страницы остаются только в кеше сборщика и не публикуются. При изменении разметки, сетевой ошибке, исчезновении событий или провале тестов предыдущая публикация Pages сохраняется. Отчёт сверки и браузерные снимки доступны в артефакте Actions `validation-report`.

В Pages публикуются только `events.js`, `index.html` и `data/catalog.json`. Источник Pages — GitHub Actions. Токен сборки должен иметь права `contents: write`, `pages: write`, `id-token: write`; права пользователя и локального плагина доступа не расширяются.

Lampa сохраняет последний каталог и личный список на устройстве. Кнопка «Обновить» повторно загружает опубликованный каталог; она не запускает Actions. Если сеть недоступна, показывается сохранённая версия с сообщением. Кеш Pages может обновляться с задержкой.

## Проверки и разработка

Требования: Python 3.11+, Node.js 22, pnpm 11.25.0.

```sh
pip install -r requirements.txt
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
python -m unittest discover -s tests -p 'test_*.py' -v
pnpm test
```

Для установленного Chrome/Chromium задайте `CHROMIUM_PATH`. Снимки проверки интерфейса сохраняются в `test-results/` при 720p, 1080p и 4K.

```sh
python scripts/catalog.py --audit-only
python scripts/catalog.py --previous .data-work/catalog.json
python scripts/artwork.py _site/data/catalog.json
python scripts/check_release.py _site/data/catalog.json
```

Первичная сборка читает страницы списка до границы 2010 года и загружает составы только событий начиная с 1 января 2010 года, делает паузы и сохраняет прогресс. Сверка и проверки полноты применяются к этому же диапазону. Повторный запуск использует кеш. При обновлении с прежнего полного каталога события до 2010 года исключаются; исчезновение более новых событий по-прежнему блокирует публикацию. Новая версия кода отменяет устаревший запуск сборки. Не удаляйте снимок данных ради обхода ошибки сверки: сначала разберите конкретное расхождение и добавьте подтверждённое решение со ссылкой в `data/reviews.json`.

Откат публикации: вернуть предыдущий исправный коммит `main` и соответствующий проверенный снимок ветки данных, затем запустить workflow. Тесты и проверки не отключать.
