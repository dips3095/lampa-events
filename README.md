# Lampa Events

Версия **0.3.0**. Раздел UFC для Lampa: расписание, составы турниров, страницы бойцов, избранные бойцы и архив с **2010 года включительно**. Интерфейс рассчитан на телевизор и управление пультом.

Постоянный адрес расширения: **https://dips3095.github.io/lampa-events/events.js**

Добавьте его в расширения Lampa и перезапустите приложение. При обновлениях адрес менять не нужно, в том числе если ранее сохранён параметр `?v=`. Раздел меню — **«События»**. Совместимость с конкретной сборкой на LG C2 требует проверки на телевизоре.

## Каталог и поиск

Главная начинается с ближайшего турнира: реальное изображение события, дата, время и переход к составу. Ниже — «Следующие турниры», «Мои бойцы», «Недавние турниры», авторская подборка «Знаковые турниры» и личный список «Посмотреть позже». «Знаковые» — фиксированный выбор известных пар главных боёв и юбилейного события; причина выбора указана на карточке.

Карточка открывает отдельную страницу турнира: место проведения, состав, вкладки основного карда, прелимов и ранних прелимов. Если источник не разделяет кард, показываются «Все бои» с пояснением. Неполные сведения не дополняются догадками; доступен и старый каталог без подробностей.

Выбор участника открывает страницу бойца: реальное фото, весовая категория, доступные основные сведения, ближайший известный соперник и история поединков UFC. «Следить» добавляет бойца на главную. История строится из доступных подробных кардов и может быть неполной; отсутствие будущего боя в каталоге не означает, что он не назначен. «Назад» возвращает на предыдущий экран с восстановлением выбранного элемента.

Время показывается в часовом поясе устройства, с подписью МСК или UTC±смещение и правильным переходом на следующую дату. Отдельно отображается время выбранной части карда. При отсутствии надёжной временной метки показывается календарная дата организатора и «Время не объявлено».

Вкладка «По годам» показывает турниры выбранного года; последний выбранный год запоминается. «Все турниры» открывает весь архив с 2010 года, порциями по 40 карточек. Фильтры находятся в одном окне: один год, серия и статус. Изменения применяются кнопкой «Применить», «Отмена» их отбрасывает. Двойной выбор диапазона и отдельный фильтр месяца удалены; конкретную дату можно ввести в поиске.

Поиск охватывает название, номер, дату и всех известных участников, включая предварительные бои. Русские имена поддерживаются через транслитерацию и словарь вариантов; не любое произвольное написание будет распознано. В обоих режимах клавиатуры «Готово» и «Отмена» доступны пультом; отмена и физическая кнопка «Назад» не применяют изменённый текст.

«Искать раздачи по этому запросу» передаёт произвольный текст штатному парсеру Lampa. На странице прошедшего турнира кнопка «Найти запись» предлагает поиск по названию/номеру или дате. У будущих и отменённых турниров этой кнопки нет. Используются существующие настройки парсера и TorrServer. Наличие события в каталоге не гарантирует наличие записи.

Используются только настоящие афиши, официальные изображения событий и фотографии бойцов. Никаких сгенерированных изображений. При отсутствии картинки или ошибке загрузки остаётся нейтральная заглушка с названием или инициалами. Реальные афиши показываются целиком, без обрезки текста.

Результаты по умолчанию скрыты и не вставляются в DOM. Кнопка на странице прошедшего турнира открывает только его итоги; «Настройки» позволяет включить постоянный показ. Рекорды, рейтинги, серии побед и повествовательные биографии не загружаются в публичную модель. Фотографии бойцов с явно обозначенным в URL поясом отфильтровываются. Актуальное расписание и оригинальные предтурнирные афиши сохраняются: будущая титульная пара или пояс на афише могут косвенно раскрыть старые результаты.

## Данные

Основной источник — архив Sherdog и страницы событий. Включены основные турниры, телевизионные серии и финалы TUF; исключены отборочные шоу и эпизоды. Полнота списка сверяется с независимым перечнем событий. Исторические варианты названий, отмены и проверенные дополнения описаны в `data/reviews.json`. Неизвестная серия или неразобранное расхождение блокируют публикацию.

Базовый сборщик сохраняет прежнюю модель каталога: идентичность события, название, дату, серию, статус, алфавитный список участников, ссылки на источники и изображения. Дополнительный этап `scripts/enrich.py` публикует схему 2: пары поединков с устойчивыми ссылками на бойцов, части карда, место, подтверждённое время, дату проверки подробностей и отдельные объекты результатов. `scripts/detail_schema.py` проверяет ссылки, поля и результаты. Клиент совместим со схемами 1 и 2 и сохраняет последний корректный каталог при повреждённом ответе.

Sherdog даёт числовые идентификаторы бойцов и исторические пары. Официальные страницы UFC дополняют части карда, расписание, фотографии и основные сведения профилей. Сопоставление официального события проверяет дату, номер либо участников; совпадения только по дате недостаточно. Время секций берётся из явных Unix-меток расписания либо калибруется по метке основного карда: некоторые поля HTML UFC помечают местное время литералом `Z`. Необоснованное время не публикуется.

Обогащение сначала обрабатывает ближайшие и последние 60 дней, затем постепенно архив. Для отсутствующего исторического HTML и официальных страниц действует общий бюджет 20 запросов за сборку; профили расширяются по 24 за сборку. Уже сохранённый HTML позволяет разобрать больше исторических кардов без дополнительных запросов. При отказе дополнительного источника сохраняются предыдущие подробности и их прежняя дата проверки; базовая публикация не теряется из-за отсутствующей необязательной биографии. Отчёт покрытия и предупреждений — `.cache/enrichment-report.json`.

Афиши берутся из инфобоксов сопоставленных событий Википедии. Название/номер и дата проверяются, в том числе для событий на общих годовых страницах. Пакетный API разрешает имена файлов в оригинальные URL Wikimedia; фотографии из статей, арены, логотипы и результаты боёв не выбираются. Изображения загружаются напрямую у поставщика, файлы афиш на Pages не копируются. Источник указан в данных события.

TheSportsDB оставлен дополнительным источником. Новая публикация блокируется, если оригинальные афиши есть менее чем у 80% прошедших событий. При недоступности API сохраняются уже известные изображения; для событий без опубликованной афиши остаются оформленные обложки.

## Обновление и публикация

GitHub Actions запускается при изменении `main`, каждые шесть часов в 03:00, 09:00, 15:00 и 21:00 UTC и вручную. Списки, составы предстоящих и недавних событий обновляются при этих запусках, базовые старые составы — не реже раза в неделю. Это периодическое обновление, а не трансляция результатов в реальном времени; расписание Actions и источники могут задерживаться. Ручной `full_refresh` принудительно перечитывает все базовые составы.

Ветка `catalog-data` хранит последний проверенный каталог, очищенные данные составов, состояние афиш и `enrichment.json` с подробностями, профилями и соответствиями идентификаторов. Исходные HTML-страницы остаются только в кеше сборщика и не публикуются. При ошибке основной сверки, исчезновении событий или провале тестов предыдущая публикация Pages сохраняется. Отчёты и браузерные снимки доступны в артефакте Actions `validation-report`.

В Pages публикуются только `events.js`, `index.html` и `data/catalog.json`. Источник Pages — GitHub Actions. Токен сборки должен иметь права `contents: write`, `pages: write`, `id-token: write`; права пользователя и локального плагина доступа не расширяются.

Lampa сохраняет последний каталог, «Посмотреть позже», избранных бойцов и настройку результатов на устройстве. Синхронизации и регистрации нет. Кнопка «Обновить» повторно загружает опубликованный каталог; она не запускает Actions. Если сеть недоступна, показывается сохранённая версия с сообщением. Кеш Pages может обновляться с задержкой.

## Проверки и разработка

Требования: Python 3.11+, Node.js 22, pnpm 11.25.0.

```sh
pip install -r requirements.txt
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
python -m unittest discover -s tests -p 'test_*.py' -v
pnpm test
```

Для установленного Chrome/Chromium задайте `CHROMIUM_PATH`. Снимки проверки интерфейса сохраняются в `test-results/` при 720p, 1080p и 4K.

```sh
python scripts/catalog.py --audit-only
python scripts/catalog.py --previous .data-work/catalog.json
python scripts/wiki_posters.py _site/data/catalog.json
python scripts/artwork.py _site/data/catalog.json
python scripts/enrich.py _site/data/catalog.json
python scripts/check_release.py _site/data/catalog.json
node scripts/preview.cjs
```

`preview.cjs` снимает главную, турнир, профиль и избранное в минимальной оболочке Lampa на настоящих данных из `_site/data/catalog.json`; изображения загружаются напрямую из источников. Файлы — `test-results/real/`. Это браузерная проверка, не подтверждение работы на физическом телевизоре. Для разбора только уже сохранённого HTML без сети: `python scripts/enrich.py _site/data/catalog.json --offline`.

Первичная сборка читает страницы списка до границы 2010 года и загружает составы только событий начиная с 1 января 2010 года, делает паузы и сохраняет прогресс. Сверка и проверки полноты применяются к этому же диапазону. Повторный запуск использует кеш. При обновлении с прежнего полного каталога события до 2010 года исключаются; исчезновение более новых событий по-прежнему блокирует публикацию. Новая версия кода отменяет устаревший запуск сборки. Не удаляйте снимок данных ради обхода ошибки сверки: сначала разберите конкретное расхождение и добавьте подтверждённое решение со ссылкой в `data/reviews.json`.

Откат публикации: вернуть предыдущий исправный коммит `main` и соответствующий проверенный снимок ветки данных, затем запустить workflow. Тесты и проверки не отключать.
